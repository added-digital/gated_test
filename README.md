# gated_game

A game made by climbing a ladder of gates, with AI as the production team.

| Folder | What |
| --- | --- |
| `sakura-kit/` | the asset kit: style contract, validator, 27 low-poly pieces, test scene, exporter (`sakura-kit/README.md`) |
| `game/` | the game project: `NOTES.md` (rung, question, evidence), `IDEAS.md` (the parking lot), `godot/` (the Godot 4.3 project) |

The ladder itself, the plan for the kit and the Mission Control dashboard live as Claude docs:

- How a game gets made — the progression to hold yourself to
- Model Library Builder — Plan
- Claude Mission Control (sessions dashboard)

Rung log: see `game/NOTES.md`. Contract changes: see `sakura-kit/breaks.md`.
